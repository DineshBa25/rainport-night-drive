# Rainport Night Drive

Drive an Acura Integra through a fictional nighttime city and its suburbs, or take off from Rainport Field in a trainer or helicopter.

## Run locally

```sh
npm ci
npm run dev
```

Open the URL printed by Vite. To build for production, run `npm run build`.

Use **WASD** to drive, **Space** to brake, and drag the scene to look around. Press **P** to pause and **O** to enter Photo Mode while paused. The on-screen controls show the flight controls when you select an aircraft.

The active model and showroom reference photos live in `public/`. Earlier Integra model versions are in `model-archive/`.
